# The Robot's Dictionary

An interactive explainer from ColourMix v3 (DIGIBAT, Imperial College London): how a dictionary a computer can read, an ontology, helped 11 large language models (LLMs) write correct programs for a colour-mixing robot's syringe pumps.

**Open the page:** https://jingyu2020.github.io/robot-dictionary/

On the page you can write the pump program yourself and run it on a digital twin of the pumps, watch the dictionary being built (categories, definitions, relationships, good practice), mix dyes with its chemistry, and see how much it helped each LLM.

The page is one self-contained file, `index.html`; everything runs in your browser. The pump twin on the page is a simulation and no robot is connected. Results come from tests run on 22 November 2026, in which every program ran on the twin.

By [Jingyu Feng](https://profiles.imperial.ac.uk/j.feng19), DIGIBAT, Department of Chemical Engineering, Imperial College London.
